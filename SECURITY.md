# Security

This is research code with no network service and no stored credentials. The only secret it
touches is your own `OPENAI_API_KEY`, read from the environment by the three `*_by_gpt.py` scripts.

If you find a problem that should not be public, email brian.92308@gmail.com instead of opening an
issue. There is no fixed response window; this is a paper-code repository, not a maintained product.
